# Treinos A, B e C

Calistenia em casa, sem equipamento: treinos curtos com cronômetro, bipes, voz e corrida guiada.

**Abrir o app:** https://ojonatasmachado.github.io/treinos/

No celular, abra o link e adicione à tela de início para usar como app, inclusive sem internet. O histórico fica salvo no próprio aparelho.
