# Treinos A, B e C

Calistenia em casa, sem equipamento: treinos curtos com cronômetro, bipes, voz e corrida guiada.

**Abrir o app:** https://ojonatasmachado.github.io/treinos/

No celular, abra o link e adicione à tela de início para usar como app, inclusive sem internet.

- Na primeira vez, o app pede o seu nome. Ele aparece no histórico e pode ser alterado no fim da página.
- O histórico fica salvo no próprio aparelho, sem login: cada pessoa usa no seu celular.
- O som do treino vira uma faixa de áudio, então os bipes e a voz continuam com a tela bloqueada. Dá para pausar e pular etapas pela tela de bloqueio.
